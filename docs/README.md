# Documentación de Conversa

Entrada principal para la versión multicliente:

- [Instalación, clientes y operación](operacion/multicliente.md).
- [Respaldos externos y recuperación](operacion/respaldos.md), incorporados en el PR de respaldos.
- [Revisión de cambios y preparación de Meta](operacion/revision-y-meta.md).

Las guías de la raíz se conservan como referencia del piloto y para no romper enlaces de instalaciones anteriores. Para nuevas instalaciones y clientes, usar esta documentación. La próxima reorganización puede mover esas referencias mediante un cambio solo de documentación; no combinarla con una migración de datos.

Los equipos con varios colaboradores no están implementados: el acceso se decide por el propietario del negocio. La presencia de `business_members` no habilita permisos compartidos. Las autorizaciones para clientes externos de Meta y las copias externas requieren configuración y verificación propias; no se dan por activas al publicar código.
